# Распознавание радужки: простая версия


##  1. Укажите свои пути в config.py

Все настройки находятся в одном файле `recognition/config.py`:

```python
DATA_DIR = Path("data/normalized")
METADATA = Path("data/metadata.csv")
KEYNET_DIR = Path("KeyNet")
KEYNET_WEIGHTS = KEYNET_DIR / "keyNet/pretrained_nets/keyNet.pt"
DEVICE = "cpu"
```

`DATA_DIR` — папка **уже нормализованных изображений** радужки.
В `KEYNET_WEIGHTS` можно указать ваш обученный `best.pt` из проекта KeyNet.
Для приложенного проекта `keynet-training` измените `KEYNET_DIR` на его путь.

Минимальный пример `metadata.csv`:

```csv
path,subject
000_L_S5000L00_norm.jpg,000
000_L_S5000L01_norm.jpg,000
000_R_S5000R00_norm.jpg,000
001_L_S5001L00_norm.jpg,001
```

Это только пример строк, не достаточный набор для обучения. `path` задаётся
относительно `DATA_DIR`. Номера людей читаются как строки: `000` не превращается в 0.
Глаз L/R определяется из имени CASIA или пути `000/L/01.png`.
Для произвольных имён добавьте столбец `eye`:

```csv
path,subject,eye
images/a.png,000,L
images/b.png,000,L
images/c.png,000,R
```

Если столбцы у вас называются иначе, измените **только** настройки:

```python
PATH_COLUMN = "image_path"
SUBJECT_COLUMN = "person_id"
EYE_COLUMN = "eye"
CSV_SEPARATOR = "," 
```

Отдельный манифест не требуется. Если `split` отсутствует, люди автоматически
разделяются примерно на 70% train, 15% val и 15% test с `SEED = 42`.
Для такого разделения нужно минимум 6 людей. Один человек целиком остаётся
в одной части. **Класс распознавания — человек + глаз**, поэтому L и R различаются.

Если разделение уже известно, просто добавьте в CSV столбец `split`
со значениями `train`, `val`, `test`. Он будет использован вместо автоматического.
Частично заполненный `split` считается ошибкой. Если KeyNet обучался на этих
данных, используйте то же разделение людей. Не меняйте CSV и seed между обучением
и оценкой одного эксперимента: при изменении списка людей автоматический split
может измениться.

Необязательный столбец `mask` содержит путь маски относительно `DATA_DIR`:
0 = скрытая область, ненулевое значение = видимая ткань. Без столбца всё изображение
считается видимым. Маски должны совпадать с изображениями по размеру.

Проверить чтение CSV и размеры частей:

```bash
python -m recognition.data
```

## 2. Обучите модели

```bash
python -m recognition.train_hardnet
python -m recognition.train_agnet
```

Параметры обучения меняются в `config.py`: `EPOCHS`, `STEPS_PER_EPOCH`,
`LEARNING_RATE`. Батч состоит из `IDENTITIES_PER_BATCH` разных радужек,
по `IMAGES_PER_IDENTITY` снимков каждой. По умолчанию 2×2 = 4 снимка.
В train и val нужны минимум две радужки с двумя снимками каждой; если увеличиваете
размер батча, должно хватать радужек и снимков для выбранных P и K.

Точки KeyNet и регионы считаются при первом обращении к снимку и остаются в памяти.
Отдельной команды подготовки и файлов кэша нет. После перезапуска они считаются
снова. KeyNet заморожен и в этих скриптах не обучается.

Результаты:

```text
runs/recognition/hardnet/best.pt
runs/recognition/hardnet/last.pt
runs/recognition/hardnet/history.csv
runs/recognition/agnet/best.pt
runs/recognition/agnet/last.pt
runs/recognition/agnet/history.csv
```

HardNet выбирает `best.pt` по validation loss, AG-Net — по validation EER.
В файлах — веса для оценки, а не полное состояние продолжения обучения.
Повторный запуск начинает обучение заново и перезаписывает результаты в `RUNS_DIR`.
Для нового эксперимента поменяйте `RUNS_DIR`; старые файлы весов из предыдущего
архива не совместимы с этим упрощённым форматом.

## 3. Посчитайте метрики

Каждая ветвь отдельно:

```bash
python -m recognition.evaluate --model hardnet --split test
python -m recognition.evaluate --model agnet --split test
```

Гибрид и обе его ветви на одинаковых парах:

```bash
python -m recognition.evaluate --model hybrid --split val
python -m recognition.evaluate --model hybrid --split test
```

Первый запуск выбирает пороги на val и записывает `thresholds.json`.
Второй показывает test EER, а также FAR/FRR при сохранённых validation-порогах.
Без предварительного val запуска будет только EER с диагностическим порогом test.
Сам EER считается по всей кривой; при фиксированном пороге FAR и FRR могут отличаться.

Результаты находятся в `runs/recognition/evaluation/<model>/`:
`val_scores.csv`, `test_scores.csv`, `val_metrics.json`, `test_metrics.json`.
Для отдельных ветвей тоже можно сначала запустить `--split val`, чтобы получить
FAR/FRR на фиксированном пороге. Не меняйте веса, настройки модели и сопоставления
между val и test. После изменения настроек заново выполните val; соответствие
старых порогов новым настройкам автоматически не проверяется.

## 5. EER отдельно, без запуска нейросетей

```bash
python -m recognition.metrics --scores runs/recognition/evaluation/hybrid/test_scores.csv --column hybrid_distance --out runs/eer
```

Для других ветвей используйте `--column hardnet_distance` или `agnet_distance`.
Можно передать собственный CSV с колонками `label,distance`, тогда `--column`
не нужен. `label=1` — одна радужка, `label=0` — разные. Чем меньше distance,
тем больше сходство. Выход: `metrics.json` и `curve.csv` для графика FAR/FRR.
`eer` — доля, `eer_percent` — проценты. Модулю метрик нужен только NumPy.

## Что внутри моделей

**HardNet:** патч 32×32 → нормированный дескриптор из 128 чисел. Положительная
пара — два преобразования одного патча; отрицательный пример выбирается из другой
радужки. Это синтетические соответствия: реальной разметки соответствующих точек
между снимками у нас нет. Не любые два патча одного глаза являются соответствиями.

**AG-Net:** ResNet-50, пространственное attention, регионы KeyNet/GMM,
RoIAlign 7×7, SE-блок, межрегиональное attention и итоговый эмбеддинг.
Loss: `3 * ArcFace + 0.9 * Triplet`. `KAPPA = 22` даёт 254 региона с учётом
попарных объединений и всего изображения. Если точек меньше KAPPA, скрипт укажет
изображение: проверьте детектор, маски или уменьшите KAPPA. При нехватке памяти
уменьшайте число изображений в батче или `REGION_CHANNELS`.

Сохранились уточнения прошлой версии: 2048→128 каналов перед RoIAlign, SE-блок
с двумя свёртками и GroupNorm, эмбеддинг 256, внутренний размер attention 32.
Это конкретные решения для мест, не полностью заданных дипломом.
`PRETRAINED_BACKBONE = True` включает загрузку ImageNet-весов для ResNet-50;
по умолчанию сеть обучается с нуля без скачивания весов.

**Гибрид:**

```python
distance = 0.85 * agnet_distance + 0.15 * exp(-alpha * matches)
```

`matches` — число взаимных соответствий HardNet после ratio test и порога.
`agnet_distance` — евклидово расстояние нормированных эмбеддингов.
Коэффициенты задаются через `HYBRID_WEIGHT`, `HYBRID_ALPHA`; alpha=0.1 — стартовое
допущение, в дипломе её число не указано. Меняйте коэффициенты только по val,
после выбора фиксируйте их и один раз оценивайте test. Отдельного обучения третьей
сети нет: по диплому это объединение двух расстояний.
